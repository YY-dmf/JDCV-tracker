# VCJDtracker

「不言求职记」的独立发布版：用于秋招、实习投递管理的个人工作台。

使用原生 HTML、CSS 和 JavaScript，无需构建、无需前端依赖，可直接打开或作为静态网站部署。

## 功能

- **JD 跟踪**：可编辑表格、自动日期、居中企业标签、文字／图片详情、四态投递状态、统计和筛选、列宽调整、右键新增／复制／删除。流程中优先置顶，各状态组内按完整时间倒序排列。
- **我的简历**：PDF 上传、预览、下载、改名、替换和删除，记录更新时间。
- **学习复盘MEMO**：标题关键词搜索、自动分页、标题与日期标签、默认折叠、每条独立展开／闭合、拖动排序；展开后仍支持圆点清单、Tab 缩进和富文本编辑。
- **用户信息**：姓名、头像上传与裁剪，以及大小 slogan。
- **数据管理**：本地保存、完整备份导出与恢复、删除撤销。
- **界面**：森林绿搭配燕麦白、奶茶驼、雾蓝灰和灰调裸粉；适配桌面和手机。

主页展示 JD 跟踪与学习复盘MEMO；简历通过顶部分页访问。点击筛选栏旁的「?」查看填表说明，点击右上角头像编辑用户信息。

## 开始使用

双击 `index.html`，使用现代浏览器打开即可。

如已安装 Python，也可以在本目录运行：

```bash
python -m http.server 8080 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8080`。无需安装项目依赖。

## 上传 GitHub 与静态部署

将本目录下的文件上传至自己的 GitHub 仓库根目录即可。项目不包含构建步骤；部署静态网站时，将仓库根目录作为发布目录，入口为 `index.html`。

本项目仅依赖 `index.html`、`styles.css` 和 `app.js` 三个运行文件；它们使用相对路径，可部署到 GitHub Pages 的项目子路径。`.nojekyll` 标记此目录为普通静态文件。

## 初始数据与隐私

首次打开时，简历、投递记录和 MEMO 均为空；用户信息为默认「新用户」，没有上传头像。发布包不内置示例记录或个人附件。

所有内容保存在访问者自己浏览器的 IndexedDB 中，不会自动上传 GitHub 或同步至其他设备。此版本使用独立的 `vcjdtracker-workspace` 数据库，与其他版本分开。清空初始数据不会导致用户后续录入的记录在刷新时丢失。

直接打开文件、使用本地服务和访问线上站点时，浏览器存储可能不同。更换访问地址、浏览器或设备前，请用右上角「⇅」导出完整备份，再在新环境恢复。备份包含 PDF、图片、头像和笔记，请自行保存，不要上传到公开仓库。

## 日常操作

- 投递方框依次切换：空框（待投递）→ 蓝色 √（已投递）→ 绿色 ◷（流程中）→ 裸粉色 ×（寄了）。状态变化时自动重新排序；流程中记录在前，其他记录在后，两组内部均按日期从新到旧排列。
- 投递记录默认每页 10 条，可选择 15 条、20 条，或自定义 1–1000 条。每页条数自动保存；切换筛选或搜索时回到第一页，删除后自动收回有效页码。
- 桌面主页中，MEMO 根据 JD 面板实际高度自动计算每页标签数；手机和独立 MEMO 视图根据屏幕高度计算。展开内容在栏内滚动，保持页面长度稳定。
- MEMO 默认折叠，每条标签右上角有全屏样式的展开／收起图标，仅控制当前笔记；标题直接在标签栏编辑，展开后不重复显示；点击日期或标签空白处也可切换。展开后图标变为向内收起样式。新建笔记会自动展开，方便直接输入。
- 按住标签左侧的六点手柄拖动，可调整当前页顺序；绿色插入线提示落点，松开即可保存。也支持聚焦手柄后按 Alt+↑／↓ 跨页移动。折叠时右键选择「复制」可生成独立副本，选择「删除」可删除笔记（支持撤销）；展开后仅显示正文，Tab／Shift+Tab 仍可调整缩进。手动顺序自动保存，搜索不会重置顺序；新笔记插入最前。
- 首次填写企业时自动记录日期；企业可在同一标签内换行。
- 选中文字使用浮动工具栏设置格式；拖动表头边缘调整列宽。
- MEMO 使用 Enter 新增一行、Tab 缩进、Shift+Tab 取消缩进。
- PDF 每份最多 20 MB，JD 图片与头像每张最多 10 MB。
- 用户信息及头像裁剪在点击「保存修改」后生效。

现有记录可以直接继续使用。完整备份同时保存流程状态、每页条数和 MEMO 手动顺序；旧版备份未包含这些设置时，默认每页 10 条，笔记按时间倒序排列。

- 点击投递状态按钮时只更新状态与统计，记录保持原位；点击其他位置后再按「流程中优先、时间倒序」刷新列表。
